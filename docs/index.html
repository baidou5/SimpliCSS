SimpliCSS combines a small utility CSS engine, machine-readable design tokens, safe UI components and an experimental local MCP server. Designed for coding agents and human developers.

Agent-first usage

Models can retrieve the manifest, validate a complete class list and compile the result. The component registry exposes safe native HTML components with explicit properties.

const { validate, compile, renderComponent } = require('./index.cjs');
const classes = ['flex', 'md:grid-cols-3', 'gap-4'];
const diagnostics = validate({ classes });
if (!diagnostics.valid) throw new Error('Unsupported utilities');
const css = compile({ safelist: classes }).css;
const html = renderComponent('button', { label: 'Save', variant: 'primary' });
